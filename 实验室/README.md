# 提炼层验证实验

验证「显式提炼层」能否让创作产出从「靠心情/灵感」变成稳定可复现的流程。

## 假设

在 memory（情绪日记/创作日志）和 fiction（母题→场景→初稿→改稿）之间加一层显式提炼，能显著提高创作的启动速度和产出稳定性。

## 步骤

1. **取样**：从 memory 的情绪日记里取 3 条素材（「事业波动」「隐形劳动」「观察压力」），每条是一段未经加工的情绪记录。
2. **提炼**：对每条素材走一遍提炼流程（情绪→外部观察→创作片段），产出一个母题卡片（一句话说清这写的是什么）和一个场景素材（50 字以内的片段钩子）。
3. **检验可写性**：把 3 个场景素材给作者看，回答两个问题——「哪个你今天就想写？」「拿到这个素材你知道怎么下笔吗？」
4. **试写**：挑其中 1 个，限时 30 分钟写一个场景初稿（500 字以上即可）。
5. **对照**：拿一条没有走提炼流程的情绪日记原始记录，同样给作者看，回答同样的两个问题。

## 标准

| 判据 | 通过 | 不通过 |
|---|---|---|
| 启动速度 | 3 个素材里至少 2 个能立即下笔 | 大部分还是「不知道怎么写」 |
| 可写性 | 试写 30 分钟内出 500 字初稿 | 卡住、写不出或写出来不像自己的 |
| 提炼层可复现 | 3 条素材都走通同一流程、产出结构一致 | 每条做法都不一样、没有统一格式 |
| 优于对照 | 走过提炼的素材明显比原始记录更容易写 | 两者没区别 |

## 产出

实验记录写入本目录，包含每条素材的提炼产物和试写片段。通过则提炼流程固化到 fiction 仓库的 AGENTS.md；不通过则记录卡在哪里，作为下一步改进的输入。
